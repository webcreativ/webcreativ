## 👋 Rólam

**2003 óta** fejlesztek webes rendszereket, ebből **16+ éve WordPress és WooCommerce** környezetben. A WordPress előtt saját **CMS-rendszereket**, egyedi **backend-rendszereket és kezelőfelületeket** építettem **PHP, HTML + CSS + JavaScript és MySQL** alapokon, ezért nem csak használom a platformot, hanem értem, mi történik alatta. A programozás számomra gyerekkorom óta szenvedély, nem csak munka. Egyedül, tudatosan korlátozott ügyfélkörrel dolgozom, mert a stabil működést és a gyors, megbízható reagálást fontosabbnak tartom a mennyiségnél.

Az AI-támogatott fejlesztés (Claude) új lehetőségeket nyitott: a megszokott PHP-s világ mellett ma már **Python és TypeScript / Node.js** nyelveken is építek, egy-egy feladathoz mindig a legmegfelelőbb eszközt választva.

Ami igazán érdekel: bonyolult rendszerek finomhangolása, egyedi API-összeköttetések, szerveroldali optimalizálás, és az olyan hibák felgöngyölítése, amiket mások már feladtak. A saját munkámat segítő eszközöket is magam építem: auditálót, monitort, dashboardot, tartalomgenerátort.

## 📦 Kiemelt munkáim

### 🛡️ WP Karbantartási Dashboard &nbsp;`v1.9`
WordPress bővítmény, ami a karbantartott ügyfélweboldalak admin vezérlőpultján egy összecsukható **Webtechnikai felügyelet** panelt jelenít meg.

- **Többforrású állapot-aggregáció**: heterogén bemeneti jelekből számított, háromszintű (RAG) státuszmodell, determinisztikus kiértékeléssel
- **Eseményvezérelt telemetria** az upgrader életciklus-hookjaira építve, a végrehajtás eredetének forrásszintű, kontextusfüggő klasszifikációjával
- **Rétegzett hozzáférés-szabályozás**: capability-, nonce- és identitásalapú kérés-hitelesítés a konfigurációs végponton, jogosultság-szeparációval
- Docker-alapú tesztkörnyezet, verziózott changelog

`PHP` · `WordPress Hooks` · `jQuery` · `Admin UI` · `Docker`

### 🔍 AI Web teszt – weboldal-auditáló
Weboldalakat auditáló webalkalmazás **100 pontos, négy pillérre (4×25) épülő** pontozással és PDF-riporttal.

- **Core Web Vitals** (LCP / INP / CLS, Lighthouse, CrUX), **E-E-A-T** (HTTPS, biztonsági fejlécek, schema, szerzői attribúció), **AIO** és **GEO** felkészültség (`llms.txt`, AI-crawlerek kezelése, `robots.txt`, SPF/DMARC)
- „Miben javítható?" szekció: pontveszteség szerint rendezett javaslatok, kiemelt **gyors győzelmekkel**
- Opcionális versenytárs-összehasonlítás és AI-vezetői összefoglaló
- A PageSpeed-kvóta kimerülését kecsesen kezeli: az audit nem bukik el

`TypeScript` · `Node.js` · `Express` · `Puppeteer` · `PageSpeed Insights API`

### 🧪 WordPress-audit (CLI)
Python parancssori eszköz, ami egy megadott domaint **teljesítmény, biztonság, SEO, GEO, E-E-A-T és WordPress-specifikus** szempontból vizsgál külön „collector" modulokkal, és riportot készít belőle. Az elemzések eredményét helyi adatbázisban tárolja.

`Python` · `SQLite` · `moduláris collectorok`

### 🏗️ Site pipeline &nbsp;`v1.9` · 178 automatikus teszt
Belső, magyar nyelvű, domain-specifikus **generatív artefaktum-pipeline** a kisvállalati szolgáltatói szegmenshez.

- **Strukturált adatfelvételből** kiinduló, többlépcsős, sablonvezérelt kimenet-előállítás
- Opcionálisan **teljes, telepíthető csomag** generálása, beágyazott megfelelőségi és biztonsági konfigurációval
- Meglévő állapot esetén **bemeneti elemzés és migrációs leképezés**, kompatibilitás-megőrző címfeloldással

`TypeScript` · `Node.js` · `Generatív pipeline` · `Migrációs leképezés`

### 🛒 AI-Ready Webshop Modder &nbsp;*(fejlesztés alatt)*
Asztali alkalmazás **WooCommerce** webshopok termékleírásainak AI-val való gazdagítására, **többügyfeles** kezeléssel. „Hibrid agy" felépítés: a **helyi Ollama** (ingyenes) kinyeri a strukturált termékadatot, a felhős **Claude** csak a végső, SEO-optimalizált szöveget írja, így a költség minimális.
