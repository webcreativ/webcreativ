## 👋 About me

I have been building web systems since **2003**, and for **16+ years** of that on **WordPress and WooCommerce**. Before WordPress I built my own **CMS systems**, custom **backend systems and admin interfaces** on a **PHP, HTML + CSS + JavaScript and MySQL** foundation, so I don't just use the platform, I understand what happens underneath. Programming has been a passion since childhood, not just a job. I work solo with a deliberately limited client base, because stability and fast, reliable response matter more to me than volume.

AI-assisted development (Claude) has opened up new possibilities: alongside the familiar PHP world I now also build in **Python and TypeScript / Node.js**, always picking the most suitable tool for the job at hand.

What really interests me: fine-tuning complex systems, custom API integrations, server-side optimisation, and untangling the kind of bugs other developers gave up on. I also build my own tooling: an auditor, a monitor, a dashboard, a content generator.

## 📦 Featured work

### 🛡️ WP Maintenance Dashboard &nbsp;`v1.9`
A WordPress plugin that renders a collapsible **technical oversight** panel on the admin dashboard of maintained client sites.

- **Multi-source state aggregation**: a three-level (RAG) status model computed from heterogeneous input signals, with deterministic evaluation
- **Event-driven telemetry** built on the upgrader lifecycle hooks, with source-level, context-aware classification of execution origin
- **Layered access control**: capability-, nonce- and identity-based request authentication on the configuration endpoint, with privilege separation
- Docker-based test environment, versioned changelog

`PHP` · `WordPress Hooks` · `jQuery` · `Admin UI` · `Docker`

### 🔍 AI Web Test – website auditor
A web application that audits websites with a **100-point scoring model built on four pillars (4×25)** and PDF reporting.

- **Core Web Vitals** (LCP / INP / CLS, Lighthouse, CrUX), **E-E-A-T** (HTTPS, security headers, schema, author attribution), **AIO** and **GEO** readiness (`llms.txt`, AI crawler handling, `robots.txt`, SPF/DMARC)
- "What can be improved?" section: recommendations sorted by points lost, with highlighted **quick wins**
- Optional competitor comparison and AI-written executive summary
- Handles PageSpeed quota exhaustion gracefully: the audit does not fail

`TypeScript` · `Node.js` · `Express` · `Puppeteer` · `PageSpeed Insights API`

### 🧪 WordPress audit (CLI)
A Python command-line tool that analyses a given domain for **performance, security, SEO, GEO, E-E-A-T and WordPress-specific** aspects using separate "collector" modules, and produces a report. Results are stored in a local database.

`Python` · `SQLite` · `modular collectors`

### 🏗️ Site pipeline &nbsp;`v1.9` · 178 automated tests
An internal, Hungarian-language, domain-specific **generative artefact pipeline** for the small-business service segment.

- Multi-stage, template-driven output generation starting from **structured data intake**
- Optional generation of a **complete, deployable package** with embedded compliance and security configuration
- For existing state: **input analysis and migration mapping** with compatibility-preserving address resolution

`TypeScript` · `Node.js` · `Generative pipeline` · `Migration mapping`

### 🛒 AI-Ready Webshop Modder &nbsp;*(in development)*
A desktop application for enriching **WooCommerce** product descriptions with AI, with **multi-client** management. "Hybrid brain" architecture: a **local Ollama** model (free) extracts the structured product data, and cloud **Claude** only writes the final, SEO-optimised text, keeping costs minimal. Built-in cost tracking, backup and restore with a before/after view, CSV/Excel export.

`Python` · `Ollama` · `Claude API` · `WooCommerce REST API` · `SQLite`

### 📡 Synthetic monitoring client
A native desktop **synthetic monitoring client** for Windows.

- Scheduled, periodic **state sampling** over a configurable target set
- **State-transition detection** with multi-channel, asynchronous alerting
- Persistent event log, background mode with minimal resource footprint

`Python` · `Desktop GUI` · `Webhook integration`

### 🌐 wp-karbantartas.hu
The website of my maintenance service: **framework-free HTML / CSS / JS**, self-hosted fonts (GDPR-friendly), structured data, `llms.txt`, PHPMailer-based form, webhook-based CRM integration.

`HTML5` · `CSS3` · `Vanilla JS` · `PHPMailer`

### 🎨 Other experiments
- **Claude UI Skill** and **Claude Modern** WordPress themes: AI-assisted theme development with dark/light mode, a WCAG focus and Core Web Vitals optimisation
- **Locale-based visitor segmentation**: server-side `Accept-Language` header analysis that, in a multi-storefront setup, uses the visitor's language profile to direct the target audience to the right localised store in real time with a context-aware prompt
